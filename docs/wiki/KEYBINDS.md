<h1 align="center">KEYBINDS</h1>

> [!NOTE]
> These are bundled niri bindings. <kbd>Super</kbd> is the Meta key.

Import Compositor from Settings → Updates to install the bundled bindings. Shell shortcuts require the `bloodyShell` command in PATH; log out and back in after installation.

---

### Window Management

| Key | Action |
| --- | ------ |
| <kbd>Super</kbd> + <kbd>Tab</kbd>    | Overview         |
| <kbd>Super</kbd> + <kbd>Arrow</kbd>  | Change focus     |
| <kbd>Super</kbd> + <kbd>Number</kbd> | Change workspace |
| <kbd>Super</kbd> + <kbd>Ctrl</kbd> + <kbd>Arrow</kbd> | Change monitor |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>Arrow</kbd>  | Move window |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>Number</kbd> | Move window to workspace |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>Arrow</kbd> | Move window to monitor |
| <kbd>Super</kbd> + <kbd>[</kbd> or <kbd>]</kbd> | Move window into / out of column |
| <kbd>Super</kbd> + <kbd>Q</kbd>      | Close window     |
| <kbd>Super</kbd> + <kbd>R</kbd>      | Window width preset |
| <kbd>Super</kbd> + <kbd>M</kbd>      | Toggle window maximize |
| <kbd>Super</kbd> + <kbd>F</kbd>      | Toggle window full width |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | Toggle window fullscreen |
| <kbd>Alt</kbd> + <kbd>Tab</kbd>      | Recent window    |
