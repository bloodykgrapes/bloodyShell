### Quickshell

Quickshell needs Qt Quick, Qt SVG, and Qt Wayland. 

| Package           | Purpose                               |
| :---------------- | :------------------------------------ |
| `quickshell`      | Runs the shell and its QML interfaces |
| `qt6-base`        | Qt core                               |
| `qt6-declarative` | QML runtime modules                   |
| `qt6-svg`         | SVG support                           |
| `qt6-wayland`     | Qt Wayland platform integration       |
